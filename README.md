## Описание проекта

Этот проект представляет собой классический веб-калькулятор, созданный в рамках лабораторной работы №22. Основная цель — разработка интерактивного веб-приложения на чистом JavaScript (Vanilla JS) с использованием современных стандартов (ES6 модули) и организации кода в виде классов для лучшей поддерживаемости и безопасности.

Проект демонстрирует:
- Работу с DOM (Document Object Model).
- Обработку событий (клики по кнопкам).
- Организацию кода с использованием ES6 модулей (`import`/`export`).
- Рефакторинг "проблемного" кода (с прямым `eval`) в безопасный и валидируемый класс.

## Функциональность

Калькулятор поддерживает базовые арифметические операции:

- **Сложение** (`+`)
- **Вычитание** (`-`)
- **Умножение** (`*`)
- **Деление** (`/`)
- **Ввод десятичных дробей** (`.`)

### Особенности и ограничения

- **Поддержка стандартного ввода**: Калькулятор корректно обрабатывает последовательный ввод цифр, операций и точки.
- **Валидация ввода**:
    - Запрещает ввод двух операторов подряд (например, `5++3`).
    - Запрещает начинать выражение с оператора (кроме случая, когда это отрицательное число, но в текущей версии требуется сначала ввести `0` или число).
    - Запрещает ввод более одной точки в пределах одного числа (например, `5.2.1`).
    - Запрещает завершение выражения оператором перед нажатием `=`.
- **Обработка ошибок**:
    - При некорректном выражении (например, `10/0` или пустом операторе) на дисплее отображается сообщение **"Ошибка"**.
    - После ошибки любое нажатие (кроме `C`) автоматически очищает состояние и начинает новый ввод.
    - Кнопка **C (Clear)** полностью сбрасывает текущее выражение и состояние ошибки.

### Класс `Calculator` (описание)

Класс `Calculator` инкапсулирует в себе всё состояние и поведение калькулятора. Он не зависит напрямую от глобальных переменных и легко может быть переиспользован.

**Основные методы и свойства:**

| Свойство/Метод | Тип | Описание |
| :--- | :--- | :--- |
| `displayElement` | поле | Ссылка на DOM-элемент поля ввода. |
| `expression` | поле | Строка, хранящая текущее математическое выражение. |
| `hasError` | поле | Флаг (true/false), указывающий на состояние ошибки. |
| `init(buttonsSelector)` | метод | Инициализирует калькулятор: находит все кнопки и вешает на них обработчики. |
| `handleButtonClick(value)` | метод | Основной маршрутизатор событий. Вызывает нужные методы в зависимости от нажатой кнопки (`C`, `=`, цифра/оператор). |
| `clear()` | метод | Сбрасывает выражение и флаг ошибки, обновляет дисплей. |
| `calculate()` | метод | Вычисляет выражение, используя `safeEvaluate()`. Обрабатывает результат или ошибку. |
| `safeEvaluate(expr)` | метод | Безопасно вычисляет выражение через `eval`, предварительно проверив его с помощью `isValidExpression()`. |
| `isValidExpression(expr)` | метод | Проверяет выражение на корректность (нет двойных операторов, оператора в конце и т.д.). |
| `hasDuplicateDot()` | метод | Проверяет, есть ли уже точка в последнем вводимом числе. |
| `updateDisplay()` | метод | Обновляет текст на экране калькулятора. |
| `showError()` | метод | Переводит калькулятор в режим ошибки и выводит сообщение. |

### Схема взаимодействия компонентов

1. **Пользователь** кликает по кнопке на странице.
2. **Браузер** генерирует событие `click`.
3. **main.js** (точка входа) создает экземпляр класса `Calculator` и вызывает его метод `init()`, передавая селектор кнопок.
4. Метод `init()` находит все кнопки в DOM и для каждой назначает обработчик, который вызывает метод `handleButtonClick()`.
5. `handleButtonClick()` анализирует значение кнопки:
   - `C` → вызывает `clear()`.
   - `=` → вызывает `calculate()`.
   - иное → вызывает методы валидации (`hasDuplicateDot`, `isLastCharOperator` и т.д.) и при успехе добавляет символ в `expression`.
6. `calculate()` вызывает `safeEvaluate()`, который проверяет выражение и вычисляет его.
7. Результат или ошибка отображаются на экране через `updateDisplay()`.

## Логика работы (пошагово)

### Последовательность действий при нажатии кнопок

1. **Нажатие цифры (например, `5`)**:
   - Если было состояние ошибки → очистить.
   - Добавить `'5'` в конец строки `expression`.
   - Обновить дисплей: `"5"`.
2. **Нажатие оператора (например, `+`)**:
   - Проверить, не является ли последний символ оператором (защита от `5++`).
   - Если проверка пройдена → добавить `'+'` в `expression`.
3. **Нажатие точки (`.`)**:
   - Проверить, есть ли уже точка в последнем числе (через `hasDuplicateDot`).
   - Если нет → добавить точку.
4. **Нажатие `=`**:
   - Вызвать `calculate()` → `safeEvaluate()`.
   - Если выражение валидно → вычислить, записать результат в `expression` и на дисплей.
   - Если нет → вызвать `showError()`.
5. **Нажатие `C`**:
   - Очистить `expression` = `''`, `hasError` = `false`, дисплей = `'0'`.

### Как работает валидация ввода

Валидация встроена в метод `handleButtonClick()` и вспомогательные методы, и предотвращает создание некорректного выражения **до того, как символ попадет в строку `expression`**:

- **Запрет двойных операторов**: проверка `isLastCharOperator()` перед добавлением нового оператора.
- **Запрет ведущего оператора**: проверка, является ли `expression` пустой строкой перед добавлением оператора.
- **Запрет лишних точек**: метод `hasDuplicateDot()` сканирует последнее число (от последнего оператора до конца) на наличие точки.

### Как происходит вычисление

Вычисление осуществляется с помощью метода `safeEvaluate()`, который, в отличие от прямого вызова `eval(expression)`, выполняет следующие шаги:

1. **Проверка на пустое выражение**: если `expression` пусто, возвращает `0`.
2. **Предварительная валидация**: вызывает `isValidExpression()`, которая проверяет:
   - Начинается ли выражение с оператора (кроме `-` как знака числа — упрощенная проверка).
   - Заканчивается ли выражение на оператор (запрещено).
   - Содержит ли выражение два оператора подряд.
3. **Безопасное вычисление**: если валидация пройдена, результат возвращается через `eval()`, но в изолированном месте. Любая ошибка в `eval` (например, деление на ноль) ловится через `try...catch`.
4. **Обработка результата**: при успехе возвращает число, при ошибке — `null`, что вызывает `showError()`.

Такой подход делает код чище, безопаснее (хоть `eval` и остался, но он строго контролируется) и пригодным для дальнейшего расширения (например, добавления кнопки `√` или `%`).
